# Anvitha Shetty Portfolio

A modern, responsive portfolio website built using React and Vite.

## Features

- Responsive UI
- Smooth animations using Framer Motion
- Animated typing effect
- Projects showcase
- Internship experience
- Technical skills
- Certifications
- Downloadable resume
- Contact section

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS3
- Framer Motion
- React Icons
- React Type Animation

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
cd portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```
